# ODS 7 - Energia Limpa e Acessível

Projeto web desenvolvido durante meus estudos de desenvolvimento web, com foco na **ODS 7 da ONU: Energia Limpa e Acessível**.

O objetivo do projeto é apresentar informações sobre fontes de energia renovável, destacando sua importância para a sustentabilidade, inovação e desenvolvimento da sociedade.

---

## Sobre o projeto

Este site foi desenvolvido como um projeto acadêmico e educacional, com o propósito de conscientizar sobre a importância da energia limpa, sustentável e acessível.

O projeto apresenta diferentes fontes de energia renovável, como:

- Energia Solar
- Energia Eólica
- Energia Hidrelétrica
- Biomassa
- Energia Geotérmica

Cada seção foi criada para explicar de forma simples e visual como essas fontes funcionam e qual sua importância para um futuro mais sustentável.

---

## Objetivo

O principal objetivo foi praticar desenvolvimento front-end e, ao mesmo tempo, trabalhar um tema relevante para a sociedade.

Com este projeto, pude desenvolver melhor conceitos como:

- Estruturação de páginas com HTML
- Estilização com CSS
- Interatividade com JavaScript
- Organização de múltiplas páginas
- Navegação entre seções
- Uso de imagens e conteúdo visual
- Construção de um site informativo
